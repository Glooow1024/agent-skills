# 文献与研究进展推荐

## 工作流

从问题或种子论文确定相关性、时间范围与目标：建立基础、追踪前沿、查找方法或复现。必要时询问；不要要求用户先配置一份顶会清单。

先读取相关 Topic 已有论文、推荐记录（如有）及用户明确读过的工作，按 DOI/arXiv ID 和版本去重。优先补充尚未覆盖的方法、证据或研究脉络。无法读取时注明只相对本次已知列表排重，不宣称用户一定没读过。

有检索能力时优先使用论文原文、官方论文页、出版机构、会议论文集和作者项目页。核实标题、作者、年份、版本与发表状态；时效性状态记录核查日期。不能检索时只给带有“待核实”标记的候选线索，不声称查到了最新文献。

结合以下因素判断，避免机械地“满足一个条件即高质量”：

- 与用户研究问题的直接相关性。
- 方法、理论论证或实验是否支持贡献主张；可复现材料是否可用。
- 发表与评审状态、领域影响及其可核查依据。

允许有价值的新预印本，但明确未同行评审及证据局限。理论工作不以“必须有实验”筛除；技术报告和观点文章区分证据等级。用户明确指定顶会、年份或证据门槛时遵从；不够则少推荐，不凑数。

默认区分“前沿进展”和“经典基础”，根据 Topic 选择合适时间窗并写明。经典工作用可核查的影响或后续采用情况说明价值；提供引用量时附数据来源和查询日期，不以未经核实的“高被引”背书。前沿预印本单独标示，不与已发表工作混淆。高质量会议/期刊优先，但出版商品牌本身不是质量保证。

每项输出标题与链接、作者/年份/发表状态、为何值得读、证据与限制、建议阅读顺序。只看到摘要时不能宣称实验扎实；证据不足时读取相关章节，或保留为待评估候选，无需为了推荐精读全部论文。

# 给对话模型的论文交接提示词

将下方内容发到已经完成论文讨论的对话中。它用于保存关键信息，知识库 Agent 会另行统一格式、生成标签及维护 Topic。

---

请根据我们关于这篇论文的已有讨论，输出一份可交给另一个 AI Agent 整理入库的 Markdown 材料。不要只写论文摘要，也不要为填写栏目补造信息。请包含：

1. **论文身份**：标题、作者、年份、发表状态、DOI/arXiv ID/官方链接和讨论的版本；未知项注明未知。
2. **我的 Before Reading 原文**：我在初步了解后的认识和问题，逐字保留。如果当前上下文没有原文，明确写“原文不可得”，不要凭记忆重写。
3. **讨论后的总结**：研究问题、核心贡献、方法机制、假设、数据/实机、训练策略、实验结果、局限与其他发现。按论文类型调整；保留我们深入讨论的细节、公式和例子。
4. **关键问答与认识变化**：我提出了什么问题、最终如何理解、哪些旧结论被纠正、纠正依据是什么，还有哪些争议或猜想。不要把早期被否定的回答混入最终结论。
5. **证据与边界**：重要数字附实验条件；能确定的来源附章节/图表编号。区分论文报告、我的观点和你的推断。没有核验就说明，不编造页码和引用。
6. **待解决问题**：尚未回答、材料缺失和需要以后验证的内容；没有可核实证据时不要过度确定。
7. **可选核心图线索**：图号和说明；已有实际图片时一并提供，不能用生成图代替论文原图。

内容以准确和完整保留关键理解为主，不必预先适配知识库标签或目录。分享链接如无法由你取得就留空；关键内容必须包含在这份文本中。若对话太长而上下文不完整，请说明你实际能够覆盖的范围。

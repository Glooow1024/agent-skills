# 领域报告写作：让读者建立理解并作出判断

用于撰写或修订领域调研正文。检索、分类、数据与交付要求见 [field-survey.md](field-survey.md)；本文件负责内容怎样组织和表达。先读现稿与用户反馈，再确定修改范围。

## 先明确读者要解决什么问题

从请求与现有材料确定读者基础、阅读目的和重点：建立全景、选择方案，还是寻找研究切入点。默认读者有相关技术背景，但不熟悉这个子领域的全部术语。已知信息不再询问；只有不同答案会显著改变内容时才澄清。

写作前在内部形成论述主线：研究对象与任务是什么，需求为何难满足，主要路线怎样回应困难，证据支持哪些判断。再检查大纲中的每节是否推进这条主线。大纲是写作依据，不作为额外章节交付，也不要求用户逐节批准。

## 按理解顺序安排内容

| 内容 | 读者读完应能回答 | 组织方式 |
|---|---|---|
| 开篇 | 研究什么，有何用途，典型输入输出是什么，主要困难在哪里？ | 用具体任务引入，随后说明报告范围；少用未解释的技术名词 |
| 必要背景 | 后文区分的方法究竟哪里不同？ | 只解释理解分类所需的概念；区分研究目标、场景表示和求解方式等不同层级 |
| 问题与路线 | 为什么难，各条思路如何起作用，何时适用？ | 先解释成因，再比较方法，用代表论文支撑；详细单篇信息进入卡片 |
| 综合与比较 | 哪些方法互补、依赖或存在取舍，证据有多强？ | 固定比较条件，解释共性与差异，不用论文简称列表代替分析 |
| 选型与研究方向 | 下一步该读、选或验证什么？ | 将建议联系到输入条件、能力要求、资源约束或证据缺口 |

这是组织依据，不是必须照搬的章节模板。熟悉领域的决策者可以先读简短摘要，但摘要仍须用其能理解的语言交代具体发现。综述中的强判断应有就近证据或明确指向的展开，避免先给出一串抽象结论、让读者自行寻找解释。

范围、筛选、版本与阅读深度集中简述，放在不妨碍主线的位置。导航只帮助定位。正文不解释Agent如何搜索、排错或修订，也不增加“本次补查”“更正记录”等章节，除非用户明确要求审计或变更历史。

## 把问题写成有因果关系的分析

每个主题应覆盖以下关系，按内容选择段落与表格，不强制固定小标题或段数：

- **困难成因：**什么观测、模型或资源条件造成了什么困难？写出对象与约束，避免只说“具有挑战”。
- **解决机制：**方法引入、共享、预测或约束了什么，为什么能缓解该困难？解释关键模块的协作，不只列名称。
- **论文关系：**哪些工作采用相同思想，哪些改变了假设或计算阶段？至少展开足以支撑该分类的代表机制，其余用卡片承接。
- **证据与取舍：**哪个实验或方法条件支持结论，代价发生在哪里，结论在哪些情况下仍不确定？机制分析与实测结果分别表达。

例如，“方法A利用先验提升鲁棒性”没有交代先验的作用。应根据真实材料说明：先验提供哪种缺失信息，如何进入模型或损失，以及先验错误会影响什么。若只读到摘要且无法回答这些问题，进一步查原文，或缩小表述；不能靠顺畅的因果连接词补出不存在的证据。

同一篇论文跨主题出现时，围绕本节的问题解释相应贡献并链接原卡片，避免反复复制摘要。前沿判断应由已有局限推出，并给出可区分不同解释的验证方式；“更高效、更通用、更多数据”不足以构成研究方向。

## 句段与术语

一段围绕一个明确意思展开，句子之间有递进、因果或比较关系。先说明具体对象，再使用抽象概念；保留专业词汇，但在首次承担论证作用时简要解释。缩写再次出现无需重复展开，同义词也不必为变化句式而反复替换。

比较用平行维度：训练方式与训练方式比，输出能力与输出能力比。少用斜杠把多个概念压成短语。段首概括应能指出本段的具体发现，避免“值得注意的是”“核心在于”等空泛铺垫；对照只有在双方条件或行为都帮助理解时才保留。

表格适合简短、可扫描的并列信息。若单元格塞入多层论证、多个分号或大量换行，就把解释移到段落。关键条件留在结果附近；不要用一句笼统免责声明代替逐项区分，也不要在每节重复同一警告。

文献卡片采用稳定字段，机制与局限用完整短句说明。来源与阅读深度可放在末尾或折叠区；重复的通用筛选话术不必逐卡展示。真实的证据不足或比较矛盾须具体保留，不能为了成品整洁而隐藏。

## 编辑与验收

先做结构编辑，再做语言编辑，最后核对事实与引用。审阅重点如下：

| 检查 | 不通过时怎样改 |
|---|---|
| 只读开篇，能否复述研究对象、用途与主要困难？ | 补齐任务关系，删除尚无解释的范式清单或空泛趋势判断 |
| 每个主题能否说明“约束如何造成困难，方法如何改变它”？ | 补上机制与因果，或删去无证据的解释；不靠多列论文补长度 |
| 方法比较是否使用同层概念，并保留必要实验条件？ | 拆开不可比维度，缩小结论范围 |
| 选型和研究建议能否追溯到前文分析？ | 补证据、标明假设或移除没有依据的建议 |
| 连续读相邻段落，是否推进认识而非重述前段？ | 合并重复解释，调整顺序，删去无新增信息的结尾 |
| 修改后是否仍保留原结论的条件、来源与不确定性？ | 恢复必要限定，修正扩大或偷换的结论 |

检查用于实际改稿，不生成一篇额外的“写作质量评估”放入报告。用户只要求局部修改时，以受影响段落及其衔接为范围，不重写已认可的全文。

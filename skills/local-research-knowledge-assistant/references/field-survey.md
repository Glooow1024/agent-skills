# 领域调研：从文献集合到问题与方法地图

适用于“帮我找 N 篇某领域高质量、前沿文献，归纳痛点和路线，形成报告/图谱”等请求。用户已给范围和数量时直接推进；无需先让用户提供论文或完成精读。仅修改现有报告的交互或链接时保留已认可内容，针对性更新。

撰写或修改综述正文前，读取 [报告写作约定](survey-writing.md)。本流程负责证据、分类与交付，该约定负责读者定位、论述顺序、表达和改稿。可用 [领域调研需求模板](../assets/field-survey-request.md) 接收委托；不把模板或执行清单原样写入报告。

## 目标与范围

让读者理解：这个领域在解决哪些具体问题；为什么难；有哪些本质不同的解决思想；每条路线在什么输入、资源与假设下有效；哪些问题尚缺证据。正文形成跨论文的判断，文献卡片提供依据，避免把 N 份摘要串成长文。

根据请求确定领域定义、核心/邻接边界、目标数量、检索截止时间、读者目的和输出位置。已知信息不重复询问；未给截止日期用检索当日，未给数量则按范围提出合理目标并说明。约100篇时，6—12个问题主题、每题2—4条核心路线是合适起点，不是必须凑满的配额。用户指定规模优先；达到数量不能以低相关、同论文多版本或低证据条目充数。

默认交付在当前工作区的独立目录。调研不自动写入所有 Topic、创建 N 篇知识库笔记或提交推送；用户要求入库时再读取对应流程并尊重现有结构。已有笔记可帮助理解偏好和缺口，但经典论文不会因用户已读过就从完整领域地图中删去。

## 文献发现与质量筛选

1. 用核心术语、同义词、关键问题和路线词检索，覆盖代表性会议/期刊、arXiv、官方项目与机构技术报告。先建立超出目标数的候选池，再按证据与覆盖取舍；结合代表作的相关工作补遗漏。综述、榜单和聚合仓库可发现线索，最终条目回到一手来源。
2. 兼顾奠基工作、关键转折与最近进展。会议、知名团队/学者、优秀企业/机构、高引用是质量线索，还需判断任务相关性、机制清晰度、评估可信度和独特代表性。不因出处有名就默认可靠，也不以未核实的引用量或身份背书。
3. 对尚未确认正式录用的预印本，检查作者/机构来源、问题设定、方法、对比与消融、局限和公开材料；代码或项目页是加分项，缺失不自动否定论文。不要只从会议列表补充极少数预印本：分别检查近期预印本与正式发表文献是否覆盖主要问题，不预设比例。记录具体入选依据，不把作者性能宣称等同独立验证。
4. 用 DOI、arXiv ID、标题/作者及版本关系去重。会议版与预印本合并为一条；同名或简称相似的不同方法分别记录。首次公开年、正式发表年、当前录用状态分开，后续新增论文保留已有稳定 ID。
5. 为每篇保存原始论文页、发表状态依据及核验日期。分别判断发布平台、正式录用和正式发表，交叉检查会议/期刊与作者官方材料；arXiv页面未填写会议字段不能证明未录用。重要技术结论来自实际读过的摘要、方法、实验或局限；从摘要无法判断的机制要读正文或作者材料。按需要深入关键代表作，报告实际阅读深度，不将少量精读泛化为全部全文审阅。

在报告中简洁说明覆盖范围、选择依据、预印本比例、证据深度及遗漏风险。找不到足够合格文献时明确缺口，不宣称穷尽领域或制造“全球前 N”。

发表渠道按研究问题展开，会议举例不构成允许收录的固定名单。例如视觉/图形学可检索CVPR、ICCV、ECCV、WACV、3DV、SIGGRAPH及相关期刊；涉及机器人、建图或交互时覆盖ICRA、IROS、RSS、CoRL；学习方法还可检索ICLR、ICML、NeurIPS。相关期刊、跨学科会议、研讨会和机构技术报告也按论文内容与证据判断，准确区分主会、研讨会与预印本。核对主要主题与渠道的交叉覆盖，区分“未检索”“检索后未选中”和“实际已收录”；没有条目不能解释为该渠道没有高质量工作。

## 先理解文献，再归并问题与路线

建立或重审分类时，读取[问题与机制归类](problem-mechanism-taxonomy.md)。先为论文提取“任务与输入输出—问题成因与失败方式—核心机制—证据与边界”，形成暂定分类；综合全部样本后至少回看一次分类，合并同义主题并拆分成因或评价目标确实不同的问题。

- **问题主题**描述研究目标或能力瓶颈，例如“稀疏观测下的动态几何歧义”，不使用“效果更好”“先进方法”等空泛名称，也不把每个网络模块单列为主题。
- **技术路线**按对准问题成因的核心机制归类：增加什么信息、约束什么自由度、隔离什么干扰或减少什么重复工作。表示形式、网络架构和计算方式另列维度；只有解释清楚其如何作用于具体瓶颈，才可作为该问题下的路线依据。实现不同但机制相同的工作归并，同名架构不能自动归为同一路线。
- **多重归属**允许一篇处理多个问题或采用多条路线。每篇保留一个主主题用于目录，再配置2—5个受控标签；可覆盖问题、表示或系统机制，并标明标签类型。主归属数量与交叉覆盖数量分别统计。
- **粒度一致**同一层节点应有相近抽象程度。定义标签含义和必要的纳入/排除边界；复用已有词汇但不被旧分类束缚。长尾单篇可作为现有路线的变体，确有新原理再单列。

分类完成后，再按读者理解顺序形成综述大纲。问题与路线需有真实文献支撑；写作时发现分类混合了目标、表示和求解方式，应返回调整分类及受影响的卡片、图谱。主题如何展开见报告写作约定。

## 文献卡片与官方资源

卡片宜简洁但足以区分论文，至少包含：

- 稳定 ID、标题、作者、首次/正式发表年份（能核实时）、场所与当前状态、论文原始链接。
- 官方项目主页（若有）、官方代码仓库（独立字段）、资源核验状态；不要把论文摘要页、个人总主页或第三方复现冒充项目主页。
- 应用/研究情境与任务，必要的输入输出；具体痛点及关键假设。
- 核心机制与独特改变：相对已有做法改了什么，为何有用；关键模块需要交代协作关系，避免只列模块名。
- 代表性效果与适用边界。数值只在可核实并保留任务、数据、指标、资源/基线条件时写；否则给有依据的定性结论。不能把机制或宣传语当实验结果。
- 主主题、路线和2—5个受控标签；每项路线关联说明该篇的具体机制及来源，可融入机制段落，不必重复另列。记录具体入选依据与实际证据深度。展示时不逐卡重复通用筛选标准。作者明确报告的局限与助理根据机制推断的边界分开。

项目主页优先从论文正文/摘要/注释、官方代码 README、作者或机构网页中的链接取得；必要时再搜索论文标题＋project。核对标题、作者或论文链接，排除同名项目和第三方聚合页。记录 URL、来源依据和状态。未找到主页写“未检索到独立项目主页”；已确认 URL 但访问失败写“来源已确认，当前未能访问”，保留证据链接。不根据作者名或方法名拼造地址，也不把访问失败解释为不存在。代码仓库存在而独立主页未找到时，分别呈现这一事实。

## 综合分析与报告更新

综合分析需要比较任务、输入条件、表示、训练/优化、推理/部署和资源预算。说明“快”发生在哪一阶段、“泛化”跨什么分布、“可控”支持什么干预；协议不同的结果保留各自条件，不拼统一排行榜。缺口与研究方向由具体局限或证据不足推出，并指出可验证的技术思路。

新增文献按既有分类纳入，必要时调整分类与综合判断。更新发表状态则直接更新条目及其依据。保留稳定ID，将变化同步到正文引用、卡片、图谱、统计、词云和打包文件；数量从实际数据生成。用户明确要求固定N篇时重新筛选，有增补要求时按授权范围扩充并更新总数。中间候选和核验记录与交付产物分开，不附入正文。

## 图谱与词云

默认提供两种互补视角：

1. **问题→技术路线→论文**：路线解释如何回应问题成因，每条论文关联携带具体机制及来源，保留有依据的跨问题/跨路线边。采用该机制与实验已证明问题解决分别表达。
2. **表示/技术范式×系统流程**：例如场景如何表示，与逐实例优化、前馈预测、增量更新、物理求解怎样组合；按领域选择有解释力的轴，不能简单重命名第一张图。

大型图避免把100个节点挤在一张静态图里。提供概览和可筛选/点击的局部视图，论文节点通向卡片与原始来源。按需要补问题交叉矩阵、输入—输出能力地图、证据缺口图或时间线。图边标明关系类型；分类相似不等于引用、继承或因果，时间先后也不自动构成演进链。

词云从明确语料生成，优先使用标题/摘要中的术语文献频率（同一论文每概念最多一次）；归并同义词、缩写与翻译，去除领域名称和通用停用词。记录匹配规则、语料范围、频数与贡献论文 ID。词名不得暗示规则无法支持的含义，例如仅匹配 depth 不能称为“深度先验”。字号代表所声明的频数，不代表质量、引用量或全领域热度；不要为视觉效果手填权重。

## 可读交付与验证

领域调研默认生成可编辑 Markdown 和离线 HTML；图谱较复杂时单独 HTML，提供 PNG/SVG 图表用于引用。BibTeX 和结构化文献/图谱数据用于复用，作为同一数据源的派生文件生成，避免手工维护多份不同步信息。只打包需要交付的内容，不附未经请求的整批论文正文。

HTML 提供明确的导航目录，覆盖主要章节、问题主题和文献卡片；桌面侧栏可向左收起并恢复，长目录可分层折叠或检索。章节及卡片可独立展开/收起，并有展开全部/收起全部。目录、内部引用和外部 `#paper-id` 深链接应自动展开目标及祖先，再滚动定位；键盘可操作，移动端可阅读，打印/导出时展开正文。初始折叠层级应方便先读综述、按需看卡片，不能让正文全部不可见。

完成前同时检查内容和产物：按报告写作约定通读正文；核对数量与身份去重、分类与标签、图谱ID与关系、正文引用、资源类型与统计。工具允许时打开产物，验证目录收起与恢复、折叠后的定位、筛选和离线资源，检查图表中文与排版；不能执行的检查如实说明，不冒充完成。结构和链接检查不等于事实核验或实验复现。

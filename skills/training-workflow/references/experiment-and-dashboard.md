# 实验与看板要求

## 协议先于长训

记录研究问题、主要假设、能区分解释的实验、比较基准及决定下一步的指标。多项改动一起训练要标为组合实验，不能当单项因果证据。继承旧训练状态要注明模型/优化器/数据游标的来源；热启动改进和从共同初始化训练的消融是不同口径。

复现记录至少包含论文版本、源码commit及补丁、依赖锁定、初始权重来源/revision/hash、数据版本与清单hash、训练/验证/测试划分、预处理、帧/视角或序列选择、冻结与可训练参数、各阶段预算、优化器、学习率/预热/衰减、原始及加权损失。对论文和代码不一致处列“论文/代码/本次选择/理由/验证”，避免笼统宣称严格复现。

区分科学性选择与运行修复：微调范围、损失权重、采样分布、预算、阶段起点、分辨率等会改变实验，不能由巡检静默改变。冻结某个头的参数不保证共享主干更新后输出不变；记录实际梯度路径并验证输出。

## 数据与分布式训练

- 不只验收清单：记录请求/实际样本索引、fallback原因、epoch、采样步、rank、随机种子；验证跨rank重叠、跨轮覆盖及随机重排。小子集测试可以查实现，无法代替完整epoch覆盖核对。
- 查清框架是否自动替换sampler，划分种子与数据增强种子分别如何使用。恢复时预取可能先于epoch回调；比较连续与中断恢复后的真实样本序列，不能只核对global_step。
- 训练、即时验证和最终测试各自用途清楚。固定探针用于曲线比较；另留最终评估协议，避免不断看同一测试集再调参。任务允许的目标图使用范围需明示。
- 每次正式更新至少记录各rank完成步、采样游标、输入形状、耗时、损失和数值状态；详细大日志按体量分层保存。

## 资源与开训验证

核实GPU型号、显存、现有进程归属和可用磁盘；训练/评估使用明确资源租约或锁，不能仅依靠一次nvidia-smi。给用户保留约定的评估资源。GPU数量不是必须为2的幂；按框架支持、全局batch、采样整除及实测吞吐选择，变更world-size后重核有效batch和学习率口径。

有效全局batch = 每卡batch × world-size × 梯度累积（不含最后不完整批次的特殊规则）。batch=1不自动说明浪费，先测峰值显存、吞吐、单步耗时及重负载输入。扩大batch或累积不能偷偷改变对照方案。预计时长包含验证、保存、数据加载、阶段转换和资源等待，记录wall-clock及GPU-hours。

开训前针对风险验证：

1. 真实输入的前向/反向和优化器更新有限；必要时覆盖极端形状、最长序列、多相机/大分辨率等实际高负载。
2. 各参数组冻结/更新与LR边界符合计划；新损失记录原始值、加权值、有效样本数及对目标参数的梯度贡献。优先查单位、尺度和监督覆盖，不能只凭loss数值大小定权重。
3. 完整checkpoint含模型、优化器、scheduler、AMP scaler（若有）、RNG、数据游标和epoch/阶段。恢复后验证对应状态及所有rank推进。诊断更新不偷偷计入正式训练。
4. 原始基准、发布权重与改进模型用相同输入和评估协议验证一次，核对指标方向、聚合方式及输出图像。
5. 保存验证结果与入口代码hash，正式长训使用固定代码/配置快照；未通过的关键问题先解决。检查规模按风险选，不机械复制历史100步或固定显存阈值。

## 每个长训任务的监控面板

已有面板优先扩展；复用技术栈，不强制引入新平台。最低可用内容：

| 区域 | 必须让用户看清的信息 |
| --- | --- |
| 总览 | 实验ID/版本、当前阶段/状态、已完成与目标更新、最近更新时间、真实进程状态、吞吐/显存、含等待解释的ETA |
| 配置 | 实际resolved配置、权重和数据来源、训练策略、GPU/batch、阶段日程、损失及权重、参数组冻结/LR、复现偏差 |
| 训练曲线 | 原始与加权损失、各组LR/梯度、有效监督量及淘汰比例、原始尖峰与可选平滑；零监督与有效监督下的零误差分开 |
| 质量曲线 | 主要任务指标、同一固定样本/协议的整体及分域趋势、单场景/视角/序列趋势、聚合权重、基准和发布版权重 |
| 检查点 | 保存/评估中/排队/成功/失败的区别，checkpoint身份和步数、对应输出与指标、版本切换与恢复标记 |
| 效果对比 | 任务相应的GT/预测/误差或样例输出；图像重建支持固定ROI、并排/叠加、时间与视角切换；目标是验证具体重影等问题 |
| 运行监控 | 检测脚本心跳、模型检查时间、异常事件与诊断进度、消息发送状态、恢复次数、完成与关闭状态 |

显示数据过期/断连，不保留一个误导性的绿色运行标签。保留修复前后历史，默认比较同阶段同预算/输入。指标较好不意味着局部伪影消失；结合困难区域和时间一致性观察，避免一个平均数掩盖失败。

## 质量检查与结论

有新质量证据被唤醒时，从最近多个可比检查点看趋势、波动、学习率阶段、训练验证差距、监督覆盖和图像错误。初次出现指标解释含义/方向/比较基准。没有新评估就记录缺口，不虚构收敛。单图PSNR波动、某项接近零、batch不相同带来的loss差异，不足以自动改变配方。

结束报告给出训练耗时、版本链、配对指标/效果、故障及修复影响、复现对齐程度和下一步。完成训练、跑通代码、优于发布版、复现论文表格分别需要各自证据。
